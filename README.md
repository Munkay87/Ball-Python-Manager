# Ball Python Manager

A Python application for managing ball python records.


## Project Status

Work in Progress - Early MVP.


## Features

- Add snakes
- Automatically generate snake IDs
- Store snake information
- View snake records
- Search snake records
- Validate user input
- Save and load records using JSON


## Technologies Used

- Python
- JSON
- Git
- GitHub


## How to Run

1. Make sure Python is installed.
2. Clone or download this repository.
3. Open the project folder in VS Code.
4. Run the application with:

```bash
python Main.py
```
